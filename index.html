Hilfe

Häufige Fragen

Prüfe zunächst deine Firewall-Einstellungen. Threadstorm benötigt offene UDP-Ports 7777 und 7778 für die Godot-Netzwerkschicht. Deaktiviere ggf. vorübergehend VPN-Software.

Stelle sicher, dass Steam läuft und du eingeloggt bist – das Matchmaking nutzt die Steam-Relay-Infrastruktur. Bei anhaltenden Problemen prüfe den Verbindungstest unter Einstellungen → Netzwerk → Diagnose.

Synchronisationsfehler entstehen meist durch hohe Latenzen über 150 ms oder Paketverluste. Im Debug-HUD (F3 ingame) kannst du dein aktuelles Ping und Jitter ablesen.

Verbinde dich nach Möglichkeit per Ethernet. Bei der Godot High-Level Multiplayer API kann ein network_peer.set_refuse_new_connections(false)-Fehler seltene Phantomzustände erzeugen – melde diesen bitte als Bug.

Verifiziere die Spieldateien via Steam: Rechtsklick auf Threadstorm → Eigenschaften → Lokale Dateien → Integrität prüfen.

Fehlt eine kompatible OpenGL-Version (Godot benötigt mind. OpenGL 3.3), startet das Spiel nicht. Aktualisiere deine Grafiktreiber. Auf AMD-GPUs kann das Deaktivieren von Shader-Cache in den Grafiktreiber-Einstellungen helfen.

Reduziere die Partikeldichte unter Einstellungen → Grafik → Effekte. Threadstorm nutzt Godot's Partikelsystem intensiv für Geschoss- und Explosionseffekte, was auf älteren GPUs zu Einbrüchen führen kann.

Stelle den Anzeigemodus auf Vollbild statt Fenster-Modus – das reduziert Compositing-Overhead erheblich.

Deine Steam-ID (64-Bit) wird als Spieler-ID verwendet. Sie ist sichtbar unter Hauptmenü → Profil → Spieler-Informationen oder über steamcommunity.com/id/[dein-name]. Bitte immer mitschicken, wenn du ein Ticket erstellst.

Spielstände werden lokal im Godot-User-Daten-Verzeichnis gespeichert. Nach einem Major-Update können inkompatible Formate dazu führen, dass Saves nicht geladen werden. Dein Backup findest du unter:

%APPDATA%\Godot\app_userdata\Threadstorm\

Erstelle dir ein manuelles Backup dieses Ordners vor jedem größeren Update. Im Verlustfall bitte sofort melden – wir prüfen Wiederherstellungsmöglichkeiten.

Bug Report

Einen Bug melden

1

Reproduzierbarkeit prüfen

Versuche den Bug 2–3 Mal zu reproduzieren. Notiere dir: Unter welchen Umständen tritt er auf? (Map, Spieleranzahl, spezifische Aktion)

2

Log-Datei sammeln

Die wichtigste Datei für uns ist das Godot-Ausgabe-Log. Direkt nach dem Bug kopiere es hier:

%APPDATA%\Godot\app_userdata\Threadstorm\logs\godot.log
3

Systeminfo exportieren

Öffne ingame Einstellungen → System → Diagnose exportieren. Dies erstellt eine sysinfo.json im Installationsordner mit GPU, OS, RAM und Godot-Version – ideal als Bug-Anhang.

4

Crash-Dumps (bei Abstürzen)

Bei einem Hard-Crash erstellt Windows einen Dump. Diesen findest du unter:

%LOCALAPPDATA%\CrashDumps\Threadstorm.exe.*.dmp
5

Report abschicken

Packe Log + Sysinfo in eine ZIP-Datei und erstelle einen Report – entweder im GitHub Issues-Tracker oder direkt im Discord im #bug-reports Kanal mit dem Tag [BUG].
